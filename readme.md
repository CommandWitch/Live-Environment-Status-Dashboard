\## Live Computer Health Status \& Database



> Query, store and create database using Python and SQLite



\## Overview

This project creates a database and stores the data locally in SQLite. Built as practice for Python scripting, database operations, error handling, and version control with Git/GitHub.



\## Features

\- SQLite database for persistent, structured storage

\- Custom queries to filter and analyse data

\- Local notes and database files kept private via `.gitignore`



\## Built With

\- Python 3.14

\- SQLite3 (built-in — no extra install)

\- VS Code
